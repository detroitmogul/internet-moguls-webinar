# How To Add This Page Into ClickFunnels 1.0
### Step-by-Step Instructions (Takes ~5–10 Minutes)

---

## STEP 1 — Create a New Funnel

1. Log into your ClickFunnels account at **app.clickfunnels.com**
2. Click **"+ New Funnel"** from the dashboard
3. Select **"Create Funnel"** (classic builder)
4. Choose **"Collect Emails"** as the funnel type
5. Name it: `Internet Moguls Webinar Registration`
6. Click **"Build Funnel"**

---

## STEP 2 — Set Up the Opt-In Page Step

1. ClickFunnels will create an **Opt-In Page** step automatically
2. Click **"Edit Page"** on the Opt-In step to open the editor
3. Once the editor loads, look for the **"Settings"** icon (gear icon) in the top toolbar
4. Click **"Custom CSS / JS"** or look for the **"</> Custom Code"** option

---

## STEP 3 — Replace the Page with Custom HTML

> **Important:** ClickFunnels 1.0 allows you to add a full custom HTML page using their "Custom HTML" element or by using a blank template.

### Option A — Use a Blank Template (Recommended)

1. When the page editor opens, click **"Change Template"** (top left)
2. Search for **"Blank"** and select the completely blank template
3. Once on the blank canvas, click **"Add Element"**
4. Scroll down and select **"Custom HTML"**
5. Paste the entire contents of the `index.html` file into the HTML box
6. Click **"Save"**

### Option B — Use the Header/Footer Code Injection

1. In the page editor, click the **Settings** (gear) icon at the top
2. Click **"SEO Meta Data"** tab
3. In the **"Head Tracking Code"** box, paste everything between `<head>` and `</head>` from the HTML file (the CSS styles)
4. In the **"Body Tracking Code"** box, paste everything between `<body>` and `</body>` from the HTML file
5. Click **"Save"**

---

## STEP 4 — Add a Thank You Page

1. Go back to the funnel builder
2. Click **"+ Add New Step"**
3. Add a **"Thank You"** page — this is where WebinarFuel will redirect registrants after they sign up
4. You can use any simple thank you template for now

---

## STEP 5 — Publish and Test

1. Click **"Publish"** in the top right of the page editor
2. Copy the funnel URL from the funnel settings
3. Open the URL in a new tab to test
4. Click one of the green CTA buttons to confirm it scrolls to the WebinarFuel registration widget
5. Test a registration to confirm WebinarFuel captures it correctly

---

## NOTES

- The WebinarFuel widget is already embedded in the HTML — it will load automatically once the page is live
- All images are hosted on a permanent CDN — no need to upload anything
- The page is fully mobile responsive
- If ClickFunnels strips some styling, use **Option B** (head/body injection) for best results
